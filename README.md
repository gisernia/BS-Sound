# SoundTouch Radio

Interfaccia web locale per controllare una Bose SoundTouch e cercare radio online.

## Avvio

1. Copia `config.example.cfg` in `config.cfg`.
2. Imposta `BOSE_IP` con l'indirizzo IP della Bose.
3. Avvia il server con `./server.py`.

L'interfaccia sarà disponibile su `http://<IP-del-computer>:8765`.
